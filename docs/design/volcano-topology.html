# 层级 扩展点 组合语义 职责 / 默认实现 阶段
A. 结构槽（3）— 在配置里选用，决定「跑什么组件」
1结构槽Plugin多个可开 能力 / 场景插件：base·node·gang（P0）·hypernode·pdb·priority（P1）P0/P1
2结构槽Action有序串联 流水线阶段：repack（P0）·relief·simulate（P1）P0/P1
3结构槽Core单选互斥 搜索策略：drain 腾空法（P0）·concentration 集中度法（P1）P0/P1
B. 引擎 Session 回调（4）— plugin 在 OnSessionOpen 注册
4引擎回调AddDomainFnunion 并集 可释放单元枚举（node 一节点一单元；hypernode 更大块）；core 综合最优P0
5引擎回调AddDisruptionScoreFn加权归一化 扰动评分：base（PG数/GPU/Pod）· gang（破组/受损卡）P0
6引擎回调AddMovableFnAND 短路 可动性门控：PDB / 冻结 scope / 优先级保护P1
7引擎回调AddPredicateFnAND 短路 额外落点过滤（与 snapshot.Predicate 叠加）P1
C. 策略钩子（10）— §4.16 编排层
8策略钩子FragmentScoreFn可组合 碎片度量；默认空节点口径 (B−A)/MP0
9策略钩子FragWeightFn可组合 多层 / 多画像 KPI 加权合成P0
10策略钩子RepackBenefitFnbool 门控 收益判定：是否值得整理P0
11策略钩子TargetProfileFn可组合 目标画像来源：Pending + DefaultP0
12策略钩子DisruptionCostFn排序 victim 中断代价；资格复用 UnifiedEvictableFnP0
13策略钩子HyperNodeGradientForSubJobFn复用 整理域 / 拓扑遍历顺序复用
14策略钩子RepackDomainOrderFn域顺序 整理域枚举 / 遍历顺序P1
15策略钩子RepackPlanScoreFnargmin 多候选 plan 择优P1
16策略钩子ConsolidationGainFn精修 集中度收益 ΔΣused²P1
17策略钩子MoveScoreFn精修 单步净分 net = Σgain − λ·costP1

可调度性预言机 ValidatePlan 另复用 scheduler 的 PredicateFn · PrePredicateFn · NodeOrderFn 等。
